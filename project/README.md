# Company AI Assistant

This is the project that you build during the AI Engineering Academy.
It is an internal assistant for "Northwind Tools", a fictional company.
Use only fictional data here.

- Stack: Python, FastAPI and the Claude API.
- The academy (`../academy/index.html`) teaches the concepts and gives the tickets.
- You build each ticket here, in VS Code with Claude Code.

## Folder layout

```text
project/
  README.md        # this file
  CLAUDE.md        # tutor rules that Claude Code reads
  .env.example     # names of the environment variables, no values
  .gitignore
  tickets/         # one file per ticket, generated by the academy (do not edit)
  handoffs/        # your handoff notes, one per ticket
```

Each ticket tells you which files to add, for example `pyproject.toml`, `assistant/` and `tests/`.

## Set up

1. Copy the example environment file:

   ```sh
   cp .env.example .env
   ```

2. Fill in `.env`:
   - `ANTHROPIC_API_KEY`: your API key.
   - `ASSISTANT_MODEL`: the model that the assistant uses. The ticket recommends one.
3. Do not commit `.env`. The `.gitignore` file excludes it.

The first ticket, T-001, tells you how to create the Python environment and the packages.

## Work on a ticket

1. In the academy, finish the lesson levels that the ticket needs.
2. Open this folder in VS Code: `code ~/Documents/ai-academy/project`.
3. In the VS Code terminal, start Claude Code: `claude`.
4. Give the mode, the ticket and the milestone, for example:
   `Mode: guided. Ticket tickets/T-001.md, milestone 1.`
5. Write the code yourself. Run the tests with `pytest`.
6. Ask for a review: `Mode: review. Ticket T-001.`
7. Fill in `handoffs/<id>-handoff.md`. Bring it back to the academy, or paste it into a Claude review chat.
8. Commit when you decide to. Claude Code does not commit for you.

The academy page **VS Code workflow** explains the five modes: guided, independent, debugging, review and teach-back.

## New tickets

When the academy gets a new lesson, run this command from `~/Documents/ai-academy`:

```sh
node academy/tools/generate.js
```

It writes the new ticket files. It does not overwrite your handoff notes.
