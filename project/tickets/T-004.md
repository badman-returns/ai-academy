## 5. Functional and technical requirements

**Functional**

1. `softmax(scores: list[float]) -> list[float]` returns weights from 0 to 1 that add up to 1. It accepts `-math.inf` for masked positions and gives them weight 0.
2. `scaled_dot_product_attention(q, k, v, causal=False)` takes three matrices as lists of rows and returns a pair `(output, weights)`: the n × d_v output and the n × n weight table.
3. The function divides the scores by `√d_k`, where d_k is the length of each query and key row.
4. With `causal=True`, row i gives weight 0 to every column j > i. The mask is applied to the scores, before the softmax.
5. `python -m assistant.attention` prints the lesson's toy example ("The", "cat", "sat") as a weight table and an output table, with and without the mask, at 3 decimals.

**Technical**

1. Pure functions: no global state, no printing inside the functions, no change to the input lists.
2. The softmax subtracts the row maximum before `math.exp`, so large scores do not overflow.
3. Wrong shapes raise `ValueError` with a clear message: rows of q and k with different lengths, k and v with a different number of rows, an empty input. With `causal=True`, q and k must have the same number of rows.
4. Type hints on every public function. A docstring on `scaled_dot_product_attention` that states the formula.
5. The tests make no network call and need no API key.

## 6. Acceptance criteria

1. Given the lesson's Q, K and V with `causal=False`, when you call the function, then the weights for "sat" are 0.248, 0.503 and 0.248, and its output is [0.497, 0.752] (tolerance 0.001).
2. Given the same input with `causal=True`, then the weight rows are [1.000, 0, 0], [0.330, 0.670, 0] and [0.248, 0.503, 0.248], and the outputs are [1.000, 0.000], [0.330, 0.670] and [0.497, 0.752].
3. Given any valid input, each row of weights adds up to 1 (tolerance 1e-9), with and without the mask.
4. Given the scores 1000, 999 and 0, `softmax` returns about 0.731, 0.269 and 0.000 and raises no error.
5. Given a q row of length 2 and a k row of length 3, the function raises `ValueError`.
6. `pytest` passes with the network off. `python -m assistant.attention` prints the tables of criterion 1 and 2.
