## 2. Objective and real-world problem

Build the index path of the RAG service. `python -m assistant.ingest docs/` reads a folder of Markdown files, parses each file into a title and sections, cuts fixed-size chunks, embeds each chunk through an `Embedder` interface and writes `index/chunks.jsonl` and `index/manifest.json`. The manifest records the embedding model, the dimension, the chunker settings and a content hash for each document.

**Real-world problem.** Many RAG systems fail before the first question: the chunks lost their headings, the index was built with another model, or the documents changed and nobody knew. This ticket builds an index that names its sources, records how it was made, and gives the same bytes for the same inputs.

## 5. Functional and technical requirements

**Functional**

1. `python -m assistant.ingest docs/` reads every `.md` file under the folder, in sorted order of the relative path with `/`. It writes `index/chunks.jsonl` and `index/manifest.json` and prints one measurement line.
2. Options: `--chunk-words N` (default 20), `--embedder local|fake` (default `local`) and `--out DIR` (default `index/`).
3. The measurement line has the fields `docs`, `sections`, `chunks`, `words`, `chunk_words`, `embedder`, `dim` and `cost_usd`, in this order. With the fixture and the fake: `ingest docs=5 sections=10 chunks=11 words=152 chunk_words=20 embedder=fake-keyword-v1 dim=6 cost_usd=0`.
4. A folder with no `.md` file prints an error, writes no file and exits with code 1.
5. When the embedder fails on a chunk, the error names the chunk id and the path, no file is written, and the exit code is 1.

**Technical**

1. `assistant/ingest.py` holds the pure functions `slug`, `parse(path, text)`, `chunk(doc, size)` and `build_index(files, embedder, size)`, plus `load_docs(folder)`, `write_index(index, out)` and the `__main__` code. Only `load_docs` and `write_index` touch files.
2. Parse rules: a line that starts with `# ` is the title. A line that starts with `## ` starts a section. Text before the first section goes into the section `intro`. Words are the text split at whitespace. The document id is the file name without `.md`.
3. The section id is `<document id>#<slug>`. The slug is the heading in lowercase, with each run of other characters than `a-z` and `0-9` replaced by one `-`, and no `-` at the start or the end. A second section with the same slug gets `-2`, a third `-3`.
4. The chunker cuts the words of one document into windows of `N` words with no overlap. A chunk never holds words of two documents. The chunk id is `<document id>:<n>`, from 0. A chunk keeps every section that its words come from, in text order, with no duplicates.
5. Each line of `chunks.jsonl` is one JSON object with the keys `id`, `doc` (the path relative to the folder), `title`, `sections`, `text` and `vector`.
6. `manifest.json` has the keys `embedder` (`model`, `dim`), `chunker` (`kind` = `"fixed-words"`, `chunk_words`), `documents` (for each path, in sorted order: `sha256` and `chunks`) and `chunks` (the total). `sha256` is `short_hash` of T-016 on the file bytes. The manifest has no date and no time.
7. `assistant/embedder.py` holds the `Embedder` protocol (`model`, `dim`, `embed_documents(texts)`, `embed_query(text)`), `FastEmbedder` and `KeywordEmbedder`. Every returned vector is a list of `dim` floats with length 1, made with `normalize` of T-003.
8. `FastEmbedder` uses `TextEmbedding(model_name="BAAI/bge-small-en-v1.5")` of fastembed, `passage_embed` for the chunks and `query_embed` for a question. It imports fastembed inside the class, so the tests and the fake runs do not need the package. `model` is `"BAAI/bge-small-en-v1.5"` and `dim` is 384.
9. `KeywordEmbedder` has `model` `"fake-keyword-v1"` and `dim` 6. Its tokens are `re.findall(r"[a-z0-9]+", text.lower())`. Each dimension counts the tokens that are in one word list (below), in the order returns, warranty, delivery, it, expenses, hr. A text with no listed token raises `ValueError` through `normalize`.
10. The tests make no network call. One test of `FastEmbedder` is marked `network` and is skipped unless you allow it.

## 6. Acceptance criteria

1. Given the fixture and the fake at 20 words, the measurement line is exactly `ingest docs=5 sections=10 chunks=11 words=152 chunk_words=20 embedder=fake-keyword-v1 dim=6 cost_usd=0`.
2. Given the fixture, `parse` gives 10 sections in total, two for each file. The ids for the refund policy are `refund-policy#return-window` (30 words) and `refund-policy#damaged-items` (19 words).
3. Given the chunk sizes 10, 20, 40 and 80, the fixture gives 17, 11, 6 and 5 chunks. The longest chunk has 10, 20, 40 and 49 words.
4. Given 20 words, `refund-policy:1` has the sections `["refund-policy#return-window", "refund-policy#damaged-items"]`, and exactly five chunks have two sections: `delivery-times:0`, `refund-policy:1`, `warranty-claims:0`, `travel-expenses:0` and `vpn-setup:0`.
5. Given the fake at 20 words, the vector of `refund-policy:0` is (0.913, 0.183, 0.365, 0, 0, 0) with a tolerance of 0.001, and every vector has length 1.000.
6. Given the fake at 20 words and the probe "How many days do I have to return an unused tool?", `top_k` of T-003 on the stored vectors returns `refund-policy:0` 0.969, `refund-policy:1` 0.937 and `refund-policy:2` 0.577.
7. Given the fixture, the manifest has the hashes delivery-times `5ce7ea20baf3`, refund-policy `f99d434e4406`, warranty-claims `ebb7bc0aeef4`, travel-expenses `30388078eede` and vpn-setup `18e41fc04c47`.
8. Given two runs with the fake on the same files, `chunks.jsonl` and `manifest.json` are byte-identical.
9. Given a copy of the fixture with "45 days" changed to "30 days", only the refund-policy hash changes, to `28945264e281`.
10. Given a document with the text "Call 555-0100 for printer help." and the fake, the ingest exits with code 1, the error names the chunk id, and the output folder has no new file.
11. Given a folder with no `.md` file, the ingest exits with code 1 and writes no file.
12. With the network allowed, `FastEmbedder().embed_query("test")` returns 384 floats with length 1.000, and a real run prints `chunks=11`, `embedder=BAAI/bge-small-en-v1.5` and `dim=384`.
13. `pytest` passes with the network off. The tests of T-001 to T-016 pass without a change.
