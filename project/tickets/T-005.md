## 5. Functional and technical requirements

**Functional**

1. `layer_norm(x, eps=1e-5, gamma=None, beta=None) -> list[float]` normalizes one vector over its features. Without gamma and beta, it uses 1 and 0.
2. `feed_forward(z, w1, w2, b1=None, b2=None) -> list[float]` computes `relu(z · w1 + b1) · w2 + b2` for one vector.
3. `transformer_block(xs, params, causal=True) -> list[list[float]]` computes the pre-LN block for all tokens: `h = x + attention(LN(x)) · w_o`, then `y = h + feed_forward(LN(h))`. It uses one attention head with `w_q`, `w_k`, `w_v`, `w_o`, and it calls your T-004 attention function.
4. `count_block_parameters(d_model, d_ff, bias=True) -> dict` returns the counts for `attention`, `feed_forward`, `layer_norm` and `total`.
5. `python -m assistant.block` loads `data/block_toy.json`, runs one block, and prints a trace for each token at 3 decimals: input, layer norm 1, attention · w_o, h, layer norm 2, feed-forward, output. It also prints the parameter counts for d_model = 512 and d_ff = 2048.

**Technical**

1. Pure functions: no global state, no printing inside the functions, no change to the input lists.
2. A `BlockParams` dataclass holds the six matrices. Its constructor or a `validate()` method checks the shapes and raises `ValueError` with a message that names the matrix and both sizes.
3. The matrices use the convention of the lesson: rows are inputs and columns are outputs, so `out = vector · W`.
4. Layer norm divides by `√(variance + eps)`. A constant vector gives zeros and no error.
5. Type hints on every public function. A docstring on `transformer_block` that states the two lines of the pre-LN block.
6. The tests make no network call and need no API key.

## 6. Acceptance criteria

1. Given [2, 4, 6, 8], when you call `layer_norm`, then the result is [-1.342, -0.447, 0.447, 1.342] (tolerance 0.001). Given [20, 40, 60, 80], the result is the same.
2. Given [3, 3, 3, 3], `layer_norm` returns [0, 0, 0, 0] and raises no error.
3. Given z = [1, 2] and the W1 and W2 of the lesson's worked example, `feed_forward` returns [0.5, -1.0].
4. Given the fixture, the output of the block for "sat" is [1.236, 0.829, -0.310, 2.958] (tolerance 0.001). The lesson's interactive shows the same numbers at 2 decimals.
5. Given `w_o` and `w_2` full of zeros, the block returns its input exactly (the residual property).
6. Given the fixture with a fourth token added and `causal=True`, the outputs of the first three tokens do not change (tolerance 1e-12).
7. `count_block_parameters(512, 2048, bias=False)["total"]` is 3,145,728, and with `bias=True` it is 3,152,384.
8. `pytest` passes with the network off. `python -m assistant.block` prints the trace of criterion 4.
