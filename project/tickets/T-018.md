## 2. Objective and real-world problem

Change the T-008 endpoint into the RAG service. `POST /ask` in `assistant/api.py` takes a question, embeds it with the embedder of the T-017 index, retrieves the top chunks, sends them to Claude with the versioned system prompt `rag-answer-v1`, checks the citations and returns the answer with the chunk id, the document path and the sections of each citation. The service loads the index one time at start-up. `python -m assistant.ask` calls the same functions from the command line.

**Real-world problem.** Users trust an assistant only when they can check its answers. Many RAG demos return fluent text with no link to a source, or with a source that the model invented. This ticket returns citations that a person can open, refuses invented citations in code, and does not call the model when nothing relevant is in the index.

## 5. Functional and technical requirements

**Functional**

1. `POST /ask` takes `{"question": str, "k": int = 3, "min_score": float = 0.5}` and returns `{"status", "answer", "citations", "sources"}`. Each citation is `{"id", "doc", "sections"}`. Each source is `{"id", "score"}` with the score at 3 decimals, in the order of the ranking.
2. The status is one of the four statuses of T-008. With no chunk at or above `min_score`, the status is `no_sources`, the answer is "I don't know", and the model is not called.
3. A citation of an id that was not retrieved stays in the list with `"doc": null` and `"sections": []`, and the status is `unsupported`.
4. `GET /health` returns `{"status": "ok", "embedder", "dim", "chunks", "prompt"}` from the manifest and the prompt file. With the fake index: `{"status": "ok", "embedder": "fake-keyword-v1", "dim": 6, "chunks": 11, "prompt": "rag-answer-v1"}`.
5. The service does not start when the index folder is missing, or when the model id or the dimension of the manifest differs from the embedder. The error names both models (or the missing path) and the ingest command.
6. `python -m assistant.ask "question"` prints the retrieved chunks with their scores and the prompt. With `--live`, it calls Claude and prints the status, the answer, the citations and one measurement line: `ask status=... sources=... cited=... prompt=rag-answer-v1 embedder=... input_tokens=... output_tokens=... cache_write=... cache_read=... cost_usd=...`. Options: `--k`, `--min-score`, `--embedder local|fake` and `--index DIR`.

**Technical**

1. A new module `assistant/rag.py` holds `load_index(folder, embedder)`, `retrieve_question(question, index, embedder, k=3, min_score=0.5)` and `answer_question(question, index, embedder, ask, k=3, min_score=0.5)`. `retrieve_question` is the only retrieval code: it calls `retrieve` of T-008 with `embedder.embed_query(question)`. The endpoint, the CLI and the eval of lesson 3.3 use it.
2. `load_index` reads the manifest and every line of `chunks.jsonl` into the T-008 corpus. It does not call the embedder for the chunks.
3. `Source` of T-008 gets the fields `doc` and `sections`, with defaults, so the T-008 tests pass without a change.
4. The citation pattern accepts a chunk id: `\[([a-z0-9-]+(?::[0-9]+)?)\]`. `parse_citations` still returns the ids in order, with no duplicates.
5. The system prompt is the file `assistant/prompts/rag_answer.txt` with the version line `version: rag-answer-v1`. Add it to `prompts.lock.json`. `build_prompt` reads it through `load_prompt` of T-016. The user message keeps the T-008 format: each chunk in `<source id="...">`, then `Question:` and the question.
6. The `ask` dependency sends the system prompt as `[cached_system(text)]` of T-015. The request has exactly one breakpoint, and no source text or question is before it.
7. The app loads the embedder and the index in a `lifespan` function, one time. The handlers get them through the dependencies `get_index` and `get_embedder`, so the tests can override them. Settings: `ASSISTANT_EMBEDDER` (`local` or `fake`, default `local`) and `ASSISTANT_INDEX` (default `index/`).
8. The request model has `question` with 1 to 2,000 characters, `k` from 1 to 10, and `min_score` from 0 to 1. An invalid request gives HTTP 422.
9. Log one line for each request: the status, the retrieved ids with their scores, the cited ids, the prompt version, the embedder model, and the token counts when the model was called. Never log the API key.
10. The tests make no network call and need no API key. They build the T-017 fixture index with the fake embedder under `tmp_path` and use a fake `ask`.

## 6. Acceptance criteria

Criteria 1 to 10 use the T-017 fixture at 20 words, the fake embedder, k = 3 and `min_score` = 0.5.

1. Given "How many days do I have to return an unused tool?" and a fake model that returns "You can return an unused tool within 45 days of delivery for a full refund [refund-policy:0].", the response has the status `answered`, the sources refund-policy:0 0.969, refund-policy:1 0.937 and refund-policy:2 0.577, and the citation `{"id": "refund-policy:0", "doc": "customer/refund-policy.md", "sections": ["refund-policy#return-window"]}`.
2. Given "How many vacation days do new employees get?", the status is `no_sources`, the answer is "I don't know", the sources are empty, and the fake model is not called. With `min_score` = 0.3, the sources are delivery-times:1 0.447, delivery-times:0 0.444 and warranty-claims:1 0.400.
3. Given "Do I pay for the delivery when I return a tool?" and a fake model that returns "I don't know.", the status is `abstained`, and the sources are refund-policy:1 0.927, refund-policy:0 0.843 and refund-policy:2 0.816.
4. Given "How fast is express delivery?" and a fake model that returns "Express delivery takes 1 working day [delivery-times:0]. Express delivery costs 9 euros [delivery-times:2].", the status is `unsupported`. The citation of delivery-times:0 has the sections delivery-times#standard-delivery and delivery-times#express-delivery, and the citation of delivery-times:2 has `"doc": null` and no sections.
5. Given "How fast is express delivery?" and k = 1, the only source is delivery-times:1 with the score 1.000 and the text "the next working day.".
6. Given "What do I do if a tool arrives damaged?", the sources are refund-policy:2 0.949, warranty-claims:0 0.894 and warranty-claims:1 0.800. With k = 4, refund-policy:1 0.718 is fourth, and its citation has the sections refund-policy#return-window and refund-policy#damaged-items.
7. `GET /health` returns exactly `{"status": "ok", "embedder": "fake-keyword-v1", "dim": 6, "chunks": 11, "prompt": "rag-answer-v1"}`.
8. Given two requests in one test client, `load_index` runs one time.
9. Given an index built with the fake embedder and an embedder with the model "other-model" and the dimension 6, the start-up fails, and the error names both models. A missing index folder also stops the start-up, and the error names the path.
10. Given two different questions, the system part of the two requests is byte-identical, `count_breakpoints` of each request is 1, and the user message has the `source` tags before the line that starts with `Question:`.
11. Given an empty question, k = 0 or `min_score` = 1.5, `POST /ask` returns HTTP 422.
12. The offline prompt tests of T-016 cover `rag-answer-v1`: a change of one character in `rag_answer.txt` without a new version fails `test_changed_text_has_a_new_version`.
13. With a real key and the real index, milestone 4 records the five questions of the lesson with `--live`: the retrieved chunks, the status, the answer and the measurement line of each. If `cache_write` and `cache_read` are 0, the handoff gives the token count of the system prompt and says that it is below the minimum of 512.
14. `pytest` passes with the network off. The tests of T-001 to T-017 pass without a change.

## 10. Security, reliability, performance and cost

- **Cost:** the service does not call the model for `no_sources`. The measurement line shows the cost of each live call. The tests cost nothing.
- **Latency:** the index loads one time. A request embeds one question and computes one dot product for each chunk.
- **Trust:** every citation names a document path and the sections that a person can open. An invented id is never shown as supported.
- **Safety:** the service refuses an index from another model. The logs have no API key.
- **Testability:** the index, the embedder and the model come through dependencies, and the tests run with the network off.
